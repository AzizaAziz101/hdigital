WEBSITE DESIGN SYSTEM PROMPT
hoeft.digital — extrahiert aus index.html
============================================================
Benutze diesen Text als Vorlage-Prompt, um neue Websites im
gleichen Look & Feel zu erstellen. Ersetze nur Inhalt, Farben
und Seitennamen — alle Strukturen, Klassen und Logik bleiben.
============================================================


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. TECH STACK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- Reines HTML5 + TailwindCSS CDN + Vanilla JS
- Kein Build-Tool, kein Framework, kein npm
- TailwindCSS über CDN: <script src="https://cdn.tailwindcss.com"></script>
- Tailwind-Config inline im <script>-Tag direkt nach dem CDN-Script
- Systemschrift-Stack: -apple-system, BlinkMacSystemFont, Segoe UI, system-ui, sans-serif
- overflow-x:hidden auf <body> gegen horizontales Scrollen

Letter-Spacing (immer als CSS-Variable verwenden):

  --tracking-heading:  -0.025em  (H2, H3)
  --tracking-label:    0.14em    (Section Labels, UPPERCASE, weitläufig)

Klassen:
  .display-xl  → clamp(48px, 6.8vw, 96px) | weight 800 | line-height 0.95 | tracking -0.045em
  .display-md  → clamp(32px, 4vw, 56px)   | weight 800 | line-height 1.1  | tracking -0.025em
  .section-label → 0.7rem | weight 700 | uppercase | tracking 0.14em | color: var(--accent)

Fließtext:
  Groß:   text-lg (1.125rem), line-height 1.7
  Normal: text-base, color #6b7280 (text-gray-500), line-height 1.7
  Klein:  text-xs, text-sm für Badges/Tags

Gradient-Text (für Akzent-Wörter in Headlines):

                  background: linear-gradient(125deg, #a78bfa 0%, #c4b5fd 55%, #ddd6fe 100%)
  .g-text-light → Lila zu Hellviolett, für helle Hintergründe
                  background: linear-gradient(125deg, #6C5CF7 0%, #8B7FFF 60%, #a78bfa 100%)
  Beide: -webkit-background-clip: text; -webkit-text-fill-color: transparent; background-clip: text;

Text-Selektion: ::selection { background: rgba(108,92,247,0.15); }

4. SCROLL-ANIMATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CSS:
  .fade-in {
    opacity: 0; transform: translateY(32px);
    transition: opacity 0.8s cubic-bezier(0.16,1,0.3,1),
                transform 0.8s cubic-bezier(0.16,1,0.3,1);
  }
  .fade-in.visible { opacity: 1; transform: none; }

  @media (max-width: 767px) {
    .fade-in { transform: translateY(14px); }
  }

JavaScript (am Ende von <body>):
  const observer = new IntersectionObserver(
    entries => entries.forEach(e => { if (e.isIntersecting) e.target.classList.add('visible'); }),
    { threshold: 0.06, rootMargin: '0px 0px -40px 0px' }
  );
  document.querySelectorAll('.fade-in').forEach(el => observer.observe(el));

Staffelung: per inline style="transition-delay: 0.08s" auf zusammengehörigen Elementen.
CTA-Sektion: KEIN fade-in — Inhalt ist sofort sichtbar.
Step-Cards auf Mobile: Animation komplett deaktiviert (opacity:1, transform:none, transition:none mit !important).

7. BENTO-KARTEN-SEKTION (Referenzen / Portfolio)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Sektion: bg-canvas, py-24 px-6
Grid: grid grid-cols-1 md:grid-cols-12 gap-5

Drei-Karten-System:
  Karte 1 (7 Spalten, oben rechts abgeschnitten):
    - Hintergrund: #F7F8FC (helles Blau-Grau)
    - clip-path: polygon(0 0, 100% 0, 100% calc(100% - 28px), calc(100% - 28px) 100%, 0 100%)
    - In .clip-wrap einwickeln (filter: drop-shadow für Polygon-Form)
    - Icon oben links (dunkler Hintergrund), Badge oben rechts (.inner-badge)
    - Titel: group-hover:text-accent transition-colors
    - Tags: .tag-pill (lila Glasmorphism)
    - Stats-Grid: 3 Spalten, border-t, Zahl + Label

  Karte 2 (5 Spalten, oben links abgeschnitten, dunkel):
    - Klasse: .card-dark (background: #111117)
    - clip-path: polygon(28px 0, 100% 0, 100% 100%, 0 100%, 0 28px) direkt auf Element (kein clip-wrap)
    - Icon: rgba(255,255,255,0.07) Hintergrund
    - Text: title text-white, body rgba(255,255,255,0.72)
    - Tags: rgba(108,92,247,0.15) Hintergrund, color #a78bfa
    - Kein group-hover auf Titel (dunkel-Karten-Ausnahme)

  Karte 3 (12 Spalten, volle Breite, unten links abgeschnitten):
    - Kann Akzentfarbe als Hintergrund bekommen (var(--accent) = #6C5CF7)
    - clip-path: polygon(0 0, 100% 0, 100% 100%, 28px 100%, 0 calc(100% - 28px))
    - In .clip-wrap einwickeln
    - Flex-Layout: flex-col md:flex-row md:items-center gap-8 (Icon | Text | Tags+Link)
    - Auf Akzent-Hintergrund: alle Texte weiß, Tags rgba(255,255,255,0.18) + white border

Clip-Path Regel:
  - KEIN box-shadow auf clip-path Elementen — border läuft als Rechteck, nicht polygon-förmig
  - Stattdessen: .clip-wrap (Elternelement) mit filter: drop-shadow() — folgt der Polygon-Form
  - .clip-2 (Card 2) ist Ausnahme: direkt auf .card-dark, kein clip-wrap nötig (box-shadow funktioniert)
